# ---------------------------------------------------------------------------
# Generative engines.
#
# These crawlers do not run JavaScript, so they only ever see what is in the
# HTML response. Allowing them is deliberate: it is what makes goGerami
# citable when someone asks an assistant how to send a gift to Ethiopia.
#
# GPTBot        — OpenAI training corpus
# OAI-SearchBot — OpenAI live retrieval; this is what earns ChatGPT citations
# ChatGPT-User  — fetches a page because a user asked about it right now
# To decline training use while keeping citations, set `Disallow: /` for
# GPTBot only and leave OAI-SearchBot as it is.
# ---------------------------------------------------------------------------

Allow: /

Allow: /

User-agent: ChatGPT-User
Allow: /
